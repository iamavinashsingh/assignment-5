**Link**: https://banana-threads.netlify.app/

## Overview

The Banana Bliss Oversized T-Shirt product page is designed to showcase a product with a modern and user-friendly interface. It includes interactive elements like size selection, quantity adjustment, and modals for size charts, product descriptions, and reviews.

---

## Features

- **Interactive Size Selection**: Users can select their preferred size, and the active size is highlighted.
- **Quantity Adjustment**: Users can increase or decrease the product quantity.
- **Modals**:
  - Size Chart Modal
  - Product Description Modal
  - Customer Reviews Modal
- **Scrollable Product Suggestions**: A horizontal scrollable section for related products.
- **Responsive Design**: Optimized for desktop, tablet, and mobile devices.

---

## Technologies Used

- **HTML**: Structure of the webpage.
- **CSS**: Styling and responsive design.
- **JavaScript**: Interactive functionality.

---

## Detailed Features

### 1. **Navbar**
- Contains a brand logo, navigation links (Home, Catalog, Contact), and icons for search, user, and shopping bag.

### 2. **Product Section**
- Displays the product image, title, price, size options, quantity selector, and action buttons (Add to Cart, Buy it Now).

### 3. **Modals**
- **Size Chart Modal**: Displays a size chart image.
- **Product Description Modal**: Lists product details like fabric type, washing instructions, etc.
- **Review Modal**: Shows customer reviews with ratings.

### 4. **Scrollable Products**
- A horizontally scrollable section showcasing related products with images, titles, and prices.

### 5. **Footer**
- Includes copyright information and social media icons.

---

## Responsive Design

The page is fully responsive and adapts to different screen sizes:
- **Desktop**: Full layout with all features visible.
- **Tablet**: Adjusted spacing and font sizes.
- **Mobile**: Simplified layout with hidden navigation links and optimized product display.
